# Практическая работа №2: Разработка логических программ на языке Prolog для работы с базами знаний и решения задач поиска

## Описание

Динамическая база фактов с вводом с консоли, база знаний «Друзья» и логическая задача «Спортсмены»
(вариант 3). Интерпретатор — SWI-Prolog 10.0.2. Отчёт: [report/main.pdf](report/main.pdf).

## Задания

### 1. Создание проекта
Директория `lab_02/`, по одному файлу на задание. Запуск из неё: `swipl compare.pl`.

### 2. Динамическая база фактов
[compare.pl](compare.pl): отношения «A > B» / «A < B» вводятся с консоли до символа `#`, объекты заранее
неизвестны. Факты `bigger/2` и `object/1` — динамические (`assertz/1`), правило `greater/2` строит
транзитивное замыкание, `largest/1` и `smallest/1` находят максимальный и минимальный объекты.
Противоречивые (цикл) и повторные факты отклоняются при вводе.

Запуск: `?- start.` Пример из задания даёт самый маленький объект — вишня; самый большой единственным
не определяется (яблоко и дуриан несравнимы), с условием «яблоко < дуриан» — дуриан.

### 3. База знаний «Друзья» (вариант 3)
[friends.pl](friends.pl): факты `день_рождения/5` и `хобби/3` из задания и правила `друг/2`,
`родился_в_году/3`, `родился_в_месяце/3`, `увлекается_обоими/4`.

| № | Вопрос | Запрос | Ответ |
|---|--------|--------|-------|
| 1 | Кто родился в 1988 году? | `день_рождения(Ф, И, _, _, 1988).` | Лена Иванова, Маша Сидоренко |
| 2 | Кто родился в мае? | `день_рождения(Ф, И, _, май, _).` | Маша Сидоренко |
| 3 | У кого хобби книги? | `хобби(Ф, И, книги).` | Лена Иванова |
| 4 | Какое хобби у Маши? | `хобби(_, маша, Х).` | танцы, кино |
| 5 | У кого хобби и кино, и спорт? | `хобби(Ф, И, кино), хобби(Ф, И, спорт).` | Вася Сидоренко |
| 6 | Список всех друзей | `друг(Ф, И).` | Иванова Лена, Сидоренко Вася, Сидоренко Маша |

Все ответы разом: `?- ответы.`

### 4. Логическая задача «Спортсмены» (вариант 3)
[sportsmen.pl](sportsmen.pl): метод «образовать и проверить» — перестановки видов спорта и погоды плюс пять
ограничений из условия. Запуск: `?- решить.` Единственное решение:

- Тонни — боксёр, любит дождь;
- Майкл — футболист, любит снег;
- Джон — пловец, любит солнце.

## Выводы

- Динамические предикаты (`:- dynamic`, `assertz`, `retractall`) позволяют строить базу фактов во время работы.
- Транзитивное правило завершается только на ациклических данных, поэтому противоречия отсекаются
  при добавлении факта.
- При неполных данных «самый большой» может быть не единственным (частичный порядок) — программа выводит
  все максимальные объекты.
- Логическая задача с перестановками и ограничениями решается коротко; `findall/3` + `length/2`
  показывает, что решение единственное.

## Экранные формы

Рисунки построены по реальным сессиям swipl теми же скриптами, что и в ПР1: сессия прогоняется через
псевдотерминал ([scripts/capture_session.py](../scripts/capture_session.py)), вывод без правок сохраняется
в [transcripts/](transcripts/) и отрисовывается в PNG. Пересобрать: `bash scripts/build_lab02_figures.sh`.
