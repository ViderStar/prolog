# Практическая работа №1: Установка и настройка среды логического программирования Prolog

## Описание

Установка SWI-Prolog, знакомство с интерактивной средой (top-level), загрузка и выполнение
программы «Родственные отношения» — базы фактов и правил из Приложения 1 к заданию.
Отчёт: [report/main.pdf](report/main.pdf).

## Задания

### 1. Установка среды
SWI-Prolog 10.0.2 для arm64-darwin установлен через Homebrew на macOS 26.6.2 (Apple M4 Pro).
Версия проверена командами `swipl --version` и `?- version.`

### 2. Настройка и знакомство с инструментарием
- Рабочая директория — `lab_01/`: интерпретатор запускается из неё, файлы грузятся по короткому имени.
- Освоены команды top-level: `[file].`, `consult/1`, `make.`, `listing/1`, `help/1`, `apropos/1`,
  `working_directory/2`, `ls.`, `trace.` / `notrace.` / `nodebug.`, `halt.`
- Исходники просматриваются во встроенном веб-сервере PlDoc (`doc_server(4040)`), редактируются в VS Code.

### 3. Первая программа
[family.pl](family.pl): 5 фактов `parent/2`, 6 фактов о поле, правила `father/2`, `mother/2`,
`grandparent/2` и рекурсивное `ancestor/2`.

| № | Запрос | Ответ SWI-Prolog |
|---|--------|------------------|
| 1 | `parent(tom, bob).` | `true.` |
| 2 | `parent(bob, tom).` | `false.` |
| 3 | `male(tom).` | `true.` |
| 4 | `female(tom).` | `false.` |
| 5 | `father(tom, bob).` | `true.` |
| 6 | `mother(liz, ann).` | `false.` |
| 7 | `parent(tom, X).` | `X = bob ; X = liz.` |
| 8 | `parent(X, pat).` | `X = bob.` |
| 9 | `grandparent(X, jim).` | `X = bob ; false.` |
| 10 | `ancestor(tom, X).` | `bob ; liz ; ann ; pat ; jim ; false.` |
| 11 | `parent(tom, X).` + `;` | `X = bob ; X = liz.` |
| 12 | `ancestor(X, jim).` + `;` | `pat ; tom ; bob ; false.` |
| 13 | `parent(X, Y).` + `;` | все 5 пар |

Все ответы совпадают с ожидаемыми. Лишнее `false` после последнего решения в запросах 9, 10 и 12
означает, что SWI-Prolog проверил оставшиеся точки выбора и других решений не нашёл.

### 4. Анализ диагностики
[examples/errors_demo.pl](examples/errors_demo.pl) содержит намеренные ошибки. На нём показаны
предупреждения при загрузке (singleton-переменная, разрывное определение предиката) и ошибки
времени выполнения: неизвестный предикат, синтаксическая ошибка, отсутствующий файл,
ошибка в арифметике, переполнение стека при левой рекурсии.

## Выводы

- SWI-Prolog ставится одной командой и сразу готов к работе; top-level, справка и трассировщик работают в терминале.
- Трассировка по портам Call / Exit / Fail / Redo наглядно показывает поиск в глубину и возврат.
- Ответ `false` — это «не выводится из базы» (предположение замкнутого мира), а не ошибка;
  запрос к неопределённому предикату, наоборот, даёт ошибку `Unknown procedure`.

## Экранные формы

Все рисунки в отчёте построены по реальным сессиям swipl. Сессия прогоняется через псевдотерминал
([scripts/capture_session.py](../scripts/capture_session.py)), её вывод без правок сохраняется
в [transcripts/](transcripts/) и отрисовывается в PNG в виде окна терминала. Скриншоты PlDoc
сняты headless-браузером Chrome. Пересобрать всё: `bash scripts/build_lab01_figures.sh`.
